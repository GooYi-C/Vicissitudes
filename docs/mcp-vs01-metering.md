## 5. 四项数字的诚实口径

- **费用**：优先服务商账单；token 定价可按 `(P-C)×输入单价 + C×缓存输入单价 + O×输出单价` 除以百万，单位/币种/价格日期须一致。P/C/O 缺失、缓存价格不明或失败请求是否计费不明，则未测；不得把字符数代入。按次计费以服务商计费次数为准，不直接取前端请求数。
- **缓存**：`ΣC/ΣP` 是整个 prompt 的加权缓存 token 占比，须数据全覆盖且分母非零。上游没给缓存量 = 未测，不是 0。静态头 hash 只核验模板稳定；无服务商分段数据时，静态头单独命中率仍未测，不能偷换指标。
- **意图**：记录 `ΣblocksApplied/ΣblocksTotal` 时注明这是现有结构块下链率；自然语言意图是否被遵循需逐轮人工判定，不能由该数字自动替代。
- **提议**：`ΣproposeUsable/ΣproposeSeen` 是现有提议过闸率；同时记录实际提交与人工可用性，回滚样本不算落账成功。任何零分母都是未测，不是 100%。
